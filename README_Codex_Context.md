# Pacote de contexto para Codex - Projeto ARGUS IC

Este pacote reúne os documentos de contexto que devem ser adicionados ao repositório do projeto para orientar o Codex durante o desenvolvimento da Iniciação Científica.

## Como usar

1. Copie todos os arquivos deste pacote para a raiz do repositório do projeto.
2. Mantenha o arquivo `AGENTS.md` na raiz, pois ele funciona como a instrução principal para agentes de código.
3. Mantenha a pasta `docs/` com os documentos de apoio.
4. Ao abrir uma tarefa no Codex, peça para ele ler primeiro `AGENTS.md` e depois os documentos indicados nele.

## Arquivos incluídos

- `AGENTS.md`: instruções principais para o Codex.
- `.codex/project_context.md`: resumo compacto para consultas rápidas.
- `docs/01_CONTEXTO_IC_ARGUS.md`: contexto acadêmico, objetivo e diferença entre IC e TCC.
- `docs/02_ESCOPO_E_LIMITES.md`: escopo, não escopo e critérios de decisão.
- `docs/03_ARQUITETURA_TECNICA.md`: arquitetura recomendada com Flutter no frontend e Python no backend.
- `docs/04_DADOS_TREINAMENTO_E_MODELO.md`: datasets, pré-processamento, treinamento e métricas.
- `docs/05_REQUISITOS_E_FLUXOS.md`: requisitos funcionais, não funcionais e fluxos de uso.
- `docs/06_ROADMAP_E_TAREFAS_CODEX.md`: roteiro de implementação e tarefas úteis para Codex.
- `docs/07_FONTES_E_DECISOES.md`: rastreabilidade das decisões de escopo e tecnologia.

## Ideia central

Neste momento, o foco é a Iniciação Científica. Portanto, o projeto ARGUS deve ser tratado como uma pesquisa de viabilidade teórica e experimental, não como uma versão final de produto. A parte prática deve demonstrar que é possível capturar informações visuais de um ambiente interno, detectar objetos ou obstáculos relevantes, estimar distância aproximada por profundidade monocular e comunicar essas informações ao usuário por áudio.
